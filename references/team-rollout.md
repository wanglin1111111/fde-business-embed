# 团队推广：从个人试点到组织落地

## 角色分工

| 角色 | 职责 | 来源 |
|---|---|---|
| 蹲现场人 | 看真实操作、填场景卡、选最小环节 | 业务方或 FDE（既懂技术又蹲现场） |
| 推动方（拍板） | 立项决策、资源投入、对外负责 | **必须是业务负责人**（不是 IT） |
| 实现人 | 出小样、搭兜底流程 | 技术/FDE |
| 量化人 | 出数字、判定达标/回退 | 实现人+业务方共同 |
| 使用方（评判） | 小样验收、日常使用、反馈 | 业务一线 |

**铁律**：推动方 ≠ 实现人。IT 自己推自己验收 = 自评闭环，活不过两个季度。

## 试点治理

```
观察期（前 2 周）
  ├─ 人工兜底全开（AI 出草稿，人拍板）
  ├─ 每日记录：AI 输出 / 人工修正 / 错误类型
  └─ 不碰第二环节

评估点（第 2 周末）
  ├─ 出数字：准确率 / 单条耗时(AI vs 人工) / 返工率 / 使用方采纳率
  ├─ 达标 → 延长观察，逐步放开自动放行比例
  └─ 不达标 → 回查（拆法？兜底？数据？）或停止试点

停止条件（任一触发即停）
  ├─ 返工率 > 阈值（如 >50%）
  ├─ 使用方采纳率 < 阈值（如 <30%）
  ├─ 出现一次不可逆损失
  └─ 推动方（业务）不再使用
```

## 第二环节复制清单

```markdown
# 复制：<第二环节名>
前置：第一环节数字达标（附数字）
- [ ] 新场景卡（别抄第一环节的，重填五项）
- [ ] 5 问重过（尤其第 1 问数据、第 5 问推动方）
- [ ] 兜底机制重写（不同环节风险不同）
- [ ] 48 小时小样（模板+10 条+数字）
- [ ] 使用方验收
```

**禁止**：把第一环节的提示词模板直接搬来用（数据形态/风险不同，会一起复制错误）。

## 上 K8s / 上平台的顺序

个人跑通 → 沉淀可复用模板（场景卡+5 问+兜底+小样格式）→ 团队统一套用 → 才谈平台化。
平台化前确认：每个环节都有推动方（业务负责人）+ 都有数字。没数字的环节不上平台。

## 度量墙（给团队看）

```
| 环节 | 推动方 | 准确率 | 耗时(AI/人工) | 返工率 | 采纳率 | 状态 |
|---|---|---|---|---|---|---|
| 报价生成 | 业务张总 | 8/10 | 2min/15min | 10% | 90% | 已自动化 |
| 工单分派 | 业务李总 | 6/10 | 1min/8min | 30% | 60% | 观察期 |
```

让"谁在推"和"数字"都在同一张墙上——推动方缺位或数字缺失的环节，一眼可见。
